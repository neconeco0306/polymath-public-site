FIELD EXPERIMENT 002 / RE-ANALYSIS / REAL DATA

答えを教えずに、
星の影を探す。

見えない惑星の公転周期を、最初から与えずに観測データを調べる。最初に見つかったのは約18.973日。しかし、そこには思いがけない落とし穴があった。周期を半分にすると、より強い信号が現れた。

9.4874 日探索的に選んだ半周期
305 ppm後半データでの約0.0305%の減光スコア
HOW THE SEARCH UNFOLDED

うまくいったのは、最初からではない。

01

正解なしで探す。

3〜20日の周期を少しずつ変えて重ねる。最初に強い谷が現れたのは約18.98日。局所探索すると18.973日になった。

02

半分にしてみる。

恒星の光には周期の整数倍・分数倍が紛れやすい。結果を見てから半周期を追加調査すると、9.4874日が最良になった。

03

後半の観測期間で比べる。

前半で選んだ周期と位相を後半へ適用すると、約305 ppmの谷が残った。ただし探索途中に後半も参照したため、厳格な盲検ではありません。

OBSERVATION / TWO TIME WINDOWS

遠く離れた2つの観測期間に、
似た谷がある。

間違った周期ならどうなる？

事後的な半周期探索から選択。後半でも同じ位相に谷を確認。ただし正式な検出統計ではない。

18.973日前半 227 ppm / 後半 135 ppm

最初の探索で見つかった、およそ2倍周期の候補。1周期ごとに重ねても谷が残る。

10.2日前半 102 ppm / 後半 2 ppm

同じ方法で調べた対照周期。前半の谷を選んでも、後半の同位相ではほぼ再現しない。

数値は「2つの位相ビンの平均変化を負にした値」。物理的な惑星半径の推定や検出確率を示すものではありません。

HONESTY / WHAT WE DID NOT PROVE

これは「新しい惑星を発見した」話ではない。

この星系 Kepler-227 b は既知の系で、NASAは公転周期を約9.49日と記録しています。今回の探索値9.4874日はそれに近い数字ですが、解析方法は探索結果を見ながら調整したものです。

  • NASAの元データではなく、第三者が加工・再配布した公開CSVです。MAST原本との完全な同一性は未確認。
  • 18.973日を見つけた後に半周期を詳しく探索し、その過程で後半データも確認しました。後半は厳密な意味での未見データではありません。
  • 恒星活動、食連星、観測装置の誤差、多重検定による偶然の谷は今回排除していません。
  • 新発見・研究認証・独立査読・統計的有意性の証明ではなく、追試と反証へ進むための探索的再解析です。

次の実験は、期間や処理手順を先に固定し、正解を隠した別の恒星で、偽信号との識別能力を比較することです。

PROVENANCE / TRACE WHAT IS REAL

観測元は KIC 10797460（Kepler-227）。64,814行から2日ごとの中央値で正規化、極端な外れ値を除外して64,713点を使用。3–20日を0.02日幅で概観、120位相ビンに分けて2区間の平均値を比較。詳細な実装・条件は今後も更新します。
